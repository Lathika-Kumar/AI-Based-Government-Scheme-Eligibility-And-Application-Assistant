## A. Current AI/ML Architecture

### What is Actually Trained
1. **Unsupervised Semantic Manifold Projector**:
   - In Phase 22B, a TF-IDF vocabulary vectorizer (max 5,000 n-grams) and a TruncatedSVD dimensionality reduction model (384 dense components, seed=42) were fitted on the 4,734 master scheme texts (`scripts/generate_scheme_embeddings.py`).
   - Artifacts generated: `data/ml_models/scheme_embeddings.index` (7.27 MB binary matrix), `data/ml_models/query_vector_projector.json` (43.67 MB component weights), `data/ml_models/scheme_embeddings_metadata.json` (1.52 MB).
2. **What is Inference / Heuristic**:
   - The production ranking engine in `EligibleSchemeRecommendationService.java` is a **Hybrid Multi-Attribute Utility Decision Making (MADM) + Semantic Vector Space Ranker**.
   - It computes a weighted utility combination of 5 features: Occupation (0.25), Economic Need (0.25), Geographic Specificity (0.20), Benefit Impact (0.15), and Semantic Cosine Affinity (0.15).
3. **What is NOT Trained**:
   - There is **NO supervised Learning-to-Rank (LTR) model** (e.g. LambdaMART, RankNet, XGBoost Ranker) currently trained on citizen clicks or conversion labels.
   - Core distinction: `SEMANTIC EMBEDDINGS ≠ SUPERVISED MODEL TRAINING ≠ ONLINE/CONTINUOUS LEARNING`.
