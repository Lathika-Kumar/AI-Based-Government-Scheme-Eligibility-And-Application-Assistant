# Antigravity Extension Guide for SchemeBridge

This file lists the VS Code extensions recommended so Antigravity can help finish the SchemeBridge project smoothly.

## Minimum Recommended Extensions

### 1. Java Extension Pack
- Purpose: Java language support, debugging, testing, and project management.
- Best for: Spring Boot backend development.

### 2. Spring Boot Extension Pack
- Purpose: Helps with Spring Boot app creation, run/debug, and project inspection.
- Best for: Backend API development.

### 3. Maven for Java
- Purpose: Maven build support, dependency management, and lifecycle commands.
- Best for: Backend Java project build and packaging.

### 4. Lombok Annotations Support
- Purpose: Adds support for Lombok-generated code.
- Best for: Cleaner Java model and service classes.

### 5. REST Client
- Purpose: Test backend APIs directly inside VS Code.
- Best for: Checking auth, profile, schemes, documents, and admin APIs.

### 6. Thunder Client
- Purpose: Lightweight API testing tool inside VS Code.
- Best for: Fast endpoint testing before full frontend integration.

### 7. MongoDB for VS Code
- Purpose: View and inspect MongoDB data directly from VS Code.
- Best for: Database-backed backend development.

### 8. Docker
- Purpose: Container support and Docker workflow integration.
- Best for: Backend deployment and environment setup.

## Frontend Helpful Extensions

### 9. ESLint
- Purpose: Detects JavaScript/React issues early.
- Best for: Frontend code quality.

### 10. Prettier
- Purpose: Auto-formatting for consistent code style.
- Best for: React and JavaScript files.

### 11. Tailwind CSS IntelliSense
- Purpose: Better Tailwind autocomplete and class suggestions.
- Best for: Styling in the frontend.

### 12. Auto Rename Tag
- Purpose: Automatically rename paired HTML/JSX tags.
- Best for: React component editing.

### 13. Path Intellisense
- Purpose: Helps with import path autocomplete.
- Best for: Faster frontend development.

## Productivity Extensions

### 14. GitLens
- Purpose: Better Git history, blame, and repository navigation.
- Best for: Team collaboration and debugging changes.

### 15. SonarLint
- Purpose: Static code quality and security warnings.
- Best for: Cleaner backend and frontend code.

## Best Practical Set for This Project
If you want the smallest useful set, install these first:

1. Java Extension Pack
2. Spring Boot Extension Pack
3. Maven for Java
4. REST Client
5. Thunder Client
6. ESLint
7. Prettier
8. Tailwind CSS IntelliSense
9. GitLens
10. Docker

## Summary
For this project, Antigravity will work best if the workspace has strong Java backend support plus frontend development tools. The most important ones are:
- Java + Spring Boot support for the backend
- API testing tools for endpoint validation
- React/VS Code tools for the frontend
