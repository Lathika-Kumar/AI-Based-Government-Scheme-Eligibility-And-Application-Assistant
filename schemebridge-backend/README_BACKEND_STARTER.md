# Backend Starter Notes

This folder contains a starter Spring Boot structure for the SchemeBridge backend.

## What is included
- Spring Boot application class
- basic API response wrapper
- starter controllers for auth, profile, schemes, documents, applications, notifications, and admin

## Current status
The code structure is in place. Full Maven-based execution could not be verified in this environment because Maven wrapper files were not present and the Spring dependencies need to be resolved through a proper Maven build.

## Next step
Open this folder in a Java-enabled IDE or run it in an environment with Maven installed.
