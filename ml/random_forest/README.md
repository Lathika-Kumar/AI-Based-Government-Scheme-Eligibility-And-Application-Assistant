# SchemeBridge Standalone Random Forest Machine Learning Experimentation Module

This module provides a standalone, reproducible machine-learning experimentation framework for training and evaluating an ensemble **Random Forest Classifier** on citizen eligibility profiles for welfare schemes.

> **CRITICAL ARCHITECTURAL ISOLATION NOTICE:**  
> This module is strictly an **offline experimentation component**. It is **NOT** connected to, imported by, or used within the live production SchemeBridge application, Spring Boot microservices, React frontend, document extraction pipeline, or the deterministic eligibility engine (`EligibilityEngine.java`). The production application continues to use statutory boolean AST eligibility evaluation combined with hybrid multi-criteria ranking.

## 2. Dataset Used

### Dataset Origin & Labeling Note:
The raw SchemeBridge scheme catalog (`data/ml_dataset/master_schemes_4734.json`) contains official scheme definitions, but does **not** contain labeled citizen application decisions or ground truth eligibility labels. Live telemetry is strictly protected and does not yet meet the statutory sample volume threshold for production ML training.

Therefore, for this machine learning research experiment:
- We generated a synthetic citizen demographic dataset containing **5,000 samples**.
- The schema strictly mirrors SchemeBridge's production Java DTO [`CitizenEligibilityProfile.java`](file:///e:/SCHEMEBRIDGE/schemebridge-scheme-service/src/main/java/com/schemebridge/scheme/dto/request/CitizenEligibilityProfile.java).
- Ground truth labels are generated by evaluating demographic profiles against multi-criteria statutory welfare gatekeepers (small farmer support, low income/BPL aid, student scholarships, marginalized women empowerment).

### Dataset Summary:
- **Total Samples ($N$):** 5,000
- **Total Features ($D$):** 12 input features
- **Target Variable:** `eligible` (Binary: `0` = Not Eligible, `1` = Eligible)
- **Class Distribution:**
  - `0 (Not Eligible)`: 1,850 (37.0%)
  - `1 (Eligible)`: 3,150 (63.0%)

## 3. Features Used

The feature set maps 1-to-1 with SchemeBridge citizen eligibility attributes:

| Feature Name | Type | Processing | Description |
|---|---|---|---|
| `age` | Numerical | `StandardScaler` | Citizen age in years (18–75) |
| `annual_income` | Numerical | `StandardScaler` | Annual household income in INR |
| `disability_status` | Numerical/Binary | `StandardScaler` | Disability certification (0 or 1) |
| `land_ownership` | Numerical | `StandardScaler` | Agricultural landholding in acres |
| `bpl_status` | Numerical/Binary | `StandardScaler` | Below Poverty Line ration card flag |
| `gender` | Categorical | `OneHotEncoder` | `MALE`, `FEMALE`, `TRANSGENDER` |
| `state` | Categorical | `OneHotEncoder` | State/UT domicile (10 representative states) |
| `occupation` | Categorical | `OneHotEncoder` | `FARMER`, `STUDENT`, `SELF_EMPLOYED`, etc. |
| `category` | Categorical | `OneHotEncoder` | Social reservation category (`GENERAL`, `OBC`, `SC`, `ST`, `EWS`) |
| `marital_status` | Categorical | `OneHotEncoder` | `SINGLE`, `MARRIED`, `WIDOWED`, `DIVORCED` |
| `rural_urban_status` | Categorical | `OneHotEncoder` | Residential locality (`RURAL`, `URBAN`, `SEMI_URBAN`) |
| `employment_status` | Categorical | `OneHotEncoder` | `EMPLOYED`, `UNEMPLOYED`, `SELF_EMPLOYED`, `STUDENT` |

---

## 4. Preprocessing & Pipeline Architecture

Preprocessing and model training are encapsulated in a single `sklearn.pipeline.Pipeline`:
1. **`ColumnTransformer`**:
   - `StandardScaler` applied to the 5 continuous and binary numeric features.
   - `OneHotEncoder(handle_unknown='ignore', sparse_output=False)` applied to the 7 categorical features.
2. **`RandomForestClassifier`**:
   - `n_estimators=200`: 200 decision trees to ensure ensemble stability and reduce variance.
   - `random_state=42`: Fixed seed for bit-level reproducibility across environments.
   - `class_weight='balanced'`: Automatically balances tree splits proportional to class frequencies.

---

## 5. Train / Test Split

- **Split Ratio:** 80% Training ($N = 4,000$), 20% Testing ($N = 1,000$).
- **Stratification:** `stratify=y` guarantees identical class proportions in training and test sets.
- **Random State:** `42`.
